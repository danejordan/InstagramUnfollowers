# UI Makeover Plan

## Goal

Refresh the Instagram Unfollowers interface so it feels more polished, easier to scan, and more trustworthy while preserving the existing browser-console workflow and core behavior.

## Proposed Direction

Use a refined dark control-room aesthetic: crisp panels, stronger hierarchy, compact controls, clear status surfaces, and a warmer accent palette that does not read like a generic purple gradient app. The tool should still feel utilitarian because users are managing sensitive account actions.

## Scope

- [x] Add a local development preview path so the app can render on localhost for screenshots while keeping the Instagram-only guard for normal production use.
- [x] Redesign the initial state into a real launch surface with product identity, concise status context, and a prominent run action.
- [x] Refresh the header, toolbar buttons, search field, and progress bar with better spacing, contrast, disabled states, and responsive behavior.
- [x] Polish the scanning layout: sidebar controls, filter chips, summary stats, tabs, account rows, badges, selection affordances, and unfollow action.
- [x] Polish settings and toast styling so overlays match the refreshed interface.
- [ ] Verify with a production build and local browser screenshots at desktop and mobile sizes.

## Implementation Notes

- Keep changes tightly scoped to UI components and SCSS.
- Prefer existing Preact/React structure and avoid new dependencies.
- Preserve existing data flow, whitelist storage, scan/unfollow behavior, and export actions.
- Use typed arrow functions for new standalone helpers.
- Comments should explain constraints only, not restate the code.
